# PK13 — Orçamento Virtual

Site demonstrativo do estúdio PK13, desenvolvido com HTML, CSS, Bootstrap e JavaScript.

## Como executar

Abra `index.html` em um navegador ou utilize um servidor local de desenvolvimento.

## Páginas

- `index.html`: página inicial
- `vitrine.html`: apresentação dos serviços
- `portfolio.html`: portfólio
- `orcamento.html`: cálculo estimativo e finalização do orçamento pelo WhatsApp

## Observações

- O WhatsApp é aberto apenas após o envio válido do formulário de orçamento. O usuário precisa confirmar o envio da mensagem no aplicativo.
- Não há backend nem armazenamento de dados de clientes.
- Os valores são demonstrativos e devem ser validados pelo proprietário.
- As imagens atuais são provisórias e serão substituídas por fotografias autorizadas do estúdio.
- O número de WhatsApp não é exibido na interface, mas pode ser encontrado no código-fonte de um site estático e no link de destino.


## Fotografias
Imagens otimizadas em `assets/fotos/`, fornecidas e autorizadas pelo proprietário do PK13 Studio. Direitos das fotografias reservados ao estúdio; a publicação do código não concede licença de reutilização das imagens.


### Cabeçalho compartilhado
O menu de todas as páginas é gerado por `js/header.js`, e sua aparência é definida em `css/style.css`. Para alterar links ou rótulos do menu, edite apenas `js/header.js`. O item Sobre aponta para a seção da página inicial.
